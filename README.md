# Sổ thuế 2026 — funnel bán hàng
Link bán: https://yvalentinaniehra.github.io/so-thue-2026/ · Link bio: https://yvalentinaniehra.github.io/so-thue-2026/link/ · Kiểm cấu hình nhanh: mở link bán thêm ?check=1 để xem 4 ô bankId / accountNo / accountName / zalo "đã có" hay "còn trống".
Điền cấu hình: trong index.html sửa CONFIG.bankId (mã ngân hàng, ví dụ 970436), CONFIG.accountNo, CONFIG.accountName để bật VietQR, và CONFIG.zalo (số Zalo nhận đơn) để bật nút "Nhắn Zalo chốt đơn" ở trang cảm ơn — nút mở zalo.me kèm sẵn mã đơn + số tiền (tự copy nội dung). Ô nào trống thì đầu trang hiện 1 dòng cảnh báo gọn.
Đọc số: kpi.csv có 5 cột date,channel,event,order_id,amount; event là một trong page_view / click_buy / order_created / order_paid; channel = utm_source/utm_medium (không có UTM thì ghi direct); amount là VND (gói 150 USD quy đổi 26.300đ/USD = 3.945.000đ, chỉ để thống kê).
Vì GitHub Pages là trang tĩnh, mỗi sự kiện được trang gửi thẳng về endpoint riêng https://oztetrbtiowuihmudywj.supabase.co/functions/v1/so-thue-collector (lưu vào bảng Postgres so_thue_events và xuất trực tiếp định dạng CSV tại cùng URL, đồng thời tự động đồng bộ vào kpi.csv qua GitHub Actions sync-kpi.yml mà không cần chép tay).
Kiểm thử: đơn test chạy hết luồng đặt hàng → cảm ơn → "Tôi đã chuyển khoản", mỗi đơn sinh đúng 1 dòng order_created + 1 dòng order_paid trong kpi.csv; mã nguồn: https://github.com/yvalentinaniehra/so-thue-2026
